Keys set to the same tool form a row; the k-th key of each row is column k, one column per virtual desktop that has sessions. Put the Claude Code row above the Codex row to see a desktop's two sessions one above the other.

同じツールを選んだキーが1つの段になり、各段の k 番目のキーが k 列目になります（セッションのあるデスクトップごとに1列）。 Claude Code の段を Codex の段の上に置くと、同じデスクトップの2つが上下に並びます。
